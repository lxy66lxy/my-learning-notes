# 深度Q学习	

**深度 Q 学习（Deep Q-Learning）是一种强化学习方法：用神经网络估计“现在做哪个选择，长期收益更高”，并通过反复尝试和反馈改进选择。**

先理解**强化学习**：系统做出行动，观察结果，获得奖励，再逐渐学会怎样行动。

放到你刚才问的**客户端选择**中，可以这样理解：

| 概念                         | 在客户端选择中的例子                                 |
| ---------------------------- | ---------------------------------------------------- |
| **状态**：当前是什么情况     | 哪些客户端在线、网络速度如何、过去训练表现怎样       |
| **动作**：采取什么选择       | 本轮选择哪些客户端参加训练                           |
| **奖励**：选择后的效果评价   | 模型效果提升了多少，以及花了多少时间                 |
| **Q 值**：一个选择预计有多好 | 在当前情况下选择某客户端，预计能带来多少长期累计收益 |

假设为了简化，每轮只选一个客户端。网络给出的估计是：

- 选择甲：Q 值为 **8**
- 选择乙：Q 值为 **5**
- 选择丙：Q 值为 **3**

系统通常倾向于选择甲，但也会偶尔尝试其他客户端，避免一直依赖可能不准确的估计。

训练完成后，系统根据实际奖励，以及对后续收益的估计，修正这些 Q 值。经过多次交互，它逐渐学会在不同情况下怎样选择。

Q值通过以下方法得到：

**Q 值由神经网络根据当前状态计算出来，再通过实际行动得到的奖励不断修正。** 最开始网络参数通常是随机的，所以初始 Q 值也不可靠。

可以分成三步理解：

**① 网络先给出估计**

把当前系统情况输入网络，例如客户端是否在线、网络速度、历史训练表现等。

网络输出：“选甲预计收益多少、选乙预计收益多少……”这些就是当前估计的 Q 值。

**② 实际选一次，获得反馈**

比如选择甲参加训练，观察模型效果和耗时，按照预先设计的规则得到奖励。

然后构造一个训练参照，简化写成：

\[ 目标值=\text{本轮奖励}+\gamma\times\text{下一轮最大的估计Q值} \]

\(\gamma\) 是**折扣系数**，控制有多重视未来收益。

**③ 用目标值修正网络**

假设：

- 网络原本估计“选甲”的 Q 值是 **3**；
- 实际获得奖励 **2**；
- 下一轮最大的估计 Q 值是 **4**；
- 折扣系数为 **0.9**。

那么训练目标值就是：

\[ 2+0.9\times4=5.6 \]

训练时调整网络参数，让它对这次选择的估计**从 3 向 5.6 靠近**。

注意，**5.6 也包含对未来的估计，并不是真实收益的标准答案**。随着更多行动和反馈积累，网络反复更新 Q 值，逐渐改进决策。

**“深度”指用深度神经网络估计 Q 值**，常见实现叫**深度 Q 网络（Deep Q-Network，DQN）**。特别注意：**Q 值估计的是长期累计收益，不只是这一轮立即获得的奖励，也不是成功概率。**
