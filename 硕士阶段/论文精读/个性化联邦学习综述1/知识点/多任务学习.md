# 多任务学习

**多任务学习（Multi-Task Learning，MTL）是把多个相关任务放在一起学习，让它们互相借鉴，同时保留各自的目标和特点。**

结合个性化联邦学习，可以把**每个客户端的本地学习看成一个任务**：

- 甲：训练适合甲笔迹的数字识别模型。
- 乙：训练适合乙笔迹的数字识别模型。
- 丙：训练适合丙笔迹的数字识别模型。

虽然都在识别数字，但各家的数据分布不同，因此有各自的学习目标和模型参数。

**怎样互相借鉴？**

一种方式是利用任务之间的关系。例如，甲、乙的笔迹比较相近，可以让它们的模型更多地共享知识；丙的笔迹差异较大，则保留更多自己的特点。

这种联系可以通过**共享特征、约束相关模型的参数关系**等方式实现。各客户端优化自己的任务时，也会受到其他相关任务的帮助或约束。

| 学习方式               | 各客户端之间的关系                       |
| ---------------------- | ---------------------------------------- |
| 普通联邦学习           | 共同训练一个统一模型                     |
| 纯本地学习             | 各自训练，互不借鉴                       |
| 多任务式个性化联邦学习 | 学习多个个性化模型，并建立任务之间的联系 |

这里的关键是：**多个模型既有区别，又不是彼此孤立地训练。**

它与参数解耦也可以结合：参数解耦关注“哪些参数共享、哪些保留”，多任务学习关注“多个任务如何联合学习、互相帮助”。

个性化联邦学习（Personalized Federated Learning，PFL）希望各客户端获得适合自己的模型。

继续用你熟悉的手写数字例子：

| 客户端 | 数据特点             | 可以怎样定义本地任务     |
| ------ | -------------------- | ------------------------ |
| 甲     | 字迹倾斜、连笔较多   | 识别甲的数据分布中的数字 |
| 乙     | 字迹端正、笔画较粗   | 识别乙的数据分布中的数字 |
| 丙     | 字迹潦草、本地样本少 | 识别丙的数据分布中的数字 |

三家都识别数字，但本地数据规律不同，因此可以分别建立：

\[ \theta_{\text{甲}},\quad \theta_{\text{乙}},\quad \theta_{\text{丙}} \]

**多任务学习不是强迫三套参数最终完全一样，而是研究怎样让它们利用彼此的联系。**

例如，甲、乙的某些笔画规律接近，可以多共享；丙有特殊写法，可以保留更多本地特点。
