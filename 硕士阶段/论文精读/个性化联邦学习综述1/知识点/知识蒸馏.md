# 知识蒸馏

**知识蒸馏（Knowledge Distillation，KD）是让一个模型通过学习另一个模型的预测或中间表示，获得知识的方法。** 常把提供指导的模型叫“教师”，接受指导的模型叫“学生”。

**① 学的是什么？**

举个简化例子：只识别数字 **1、7、9**。面对一张“7”的图片，教师输出：

| 候选数字 | 教师预测概率 |
| -------- | ------------ |
| 1        | 5%           |
| 7        | 80%          |
| 9        | 15%          |

正确标签“7”只告诉学生答案是什么；教师的概率还告诉它：**老师认为“9”比“1”更有可能。**

这种概率分布叫**软标签（Soft Labels）**。学生调整自己的参数，让预测接近教师的分布，也可以同时学习真实标签。

**② 放到联邦学习中怎么做？**

一种典型方式是：

1. **准备共同的参考样本**，例如一批允许共享的图片。
2. 各客户端用自己的模型预测这些图片，交换或汇总预测分布。
3. 每个客户端==把汇总后的分布作为教师指导，训练自己的模型，并结合本地数据进行适配==。

这样，甲、乙即使模型结构不同，也可以通过**对同一批样本的预测**互相借鉴。这里还需要约定好输出类别的含义，才能比较、汇总预测。

**③ 与参数解耦有什么区别？**

| 方法         | 主要通过什么共享知识                                 |
| ------------ | ---------------------------------------------------- |
| **参数解耦** | 选出一部分模型参数，上传并聚合                       |
| **知识蒸馏** | 学习其他模型的预测或表示，可以不直接平均完整模型参数 |

所以，知识蒸馏适合实现：**各客户端保留自己的模型，同时交流模型学到的判断。** 教师也不一定是一个固定的大模型，多个客户端可以相互提供指导。

预测信息仍可能包含隐私，因此“交换预测而非原始数据”本身并不等于已经获得完整的隐私保护。
