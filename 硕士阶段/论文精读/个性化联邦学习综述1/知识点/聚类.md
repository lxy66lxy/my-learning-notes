# 聚类

**聚类（Clustering）就是根据相似程度，把对象自动分组：组内尽量相似，组间尽量不同。**

放到个性化联邦学习中，就是**把学习特点相近的客户端分到一组，让它们更多地协作**。

例如，六个客户端都在识别手写数字：

| 客户端 | 数据特点   | 可能的分组 |
| ------ | ---------- | ---------- |
| 甲、乙 | 笔迹偏倾斜 | 第一组     |
| 丙、丁 | 笔迹比较圆 | 第二组     |
| 戊、己 | 笔画比较粗 | 第三组     |

这是为了帮助理解的例子。实际算法可以根据**数据分布的统计信息、模型参数或更新方向**等判断相似程度。

分组后，一种做法是：

1. 每个客户端在本地训练。
2. 同组客户端的更新进行聚合。
3. 每组得到一个更贴合本组数据的模型。
4. 如有需要，各客户端再进一步做本地适配。

因此，系统可以有**多个组模型**；组内也仍然可以保留客户端自己的个性化部分。有些方法还会随着训练进行，重新调整分组。

与前面的方法对照：

- **客户端选择**：决定这一轮谁参与。
- **聚类**：决定哪些客户端更适合放在一起协作。

聚类希望找到合适的合作关系，但分组是否有用，还需要用任务效果来验证。
