# my-notes
一个研一学生的实用工具体验与使用笔记，并分享一些自己的学习内容

这里记录我使用编程、写作和文献管理工具的经验，希望帮助和我一样从零开始学习的人。

我会从自己实际遇到的问题出发，分享操作方法、使用心得和踩坑记录，逐步补充内容。

## 计划分享的工具
这里会记录什么

**算法与编程**

整理算法知识、题目解析和代码练习。除了记录解题方法，也会尝试说明自己的思考过程：为什么这样做、哪里容易出错，以及还有哪些疑问。

**课程学习与实践**

记录课程中的知识梳理、实验过程和问题解决方法，让学过的内容留下可以回顾的痕迹。

**文献阅读与学习方法**

分享文献整理、阅读笔记和学习过程中的体会，逐步寻找适合自己的知识整理方式。

## 关于这些记录

这些内容来自我的学习过程，可能存在理解不完整或需要修正的地方。我会尽量区分已经验证的内容和仍在探索的问题，并随着学习不断补充、修改。

引用他人的资料时，我会注明来源。也欢迎通过 GitHub 上的讨论与反馈，交流不同的理解和方法。

希望这里能慢慢成为一份看得见成长的学习记录，也能为遇到相似问题的人提供一点帮助。
