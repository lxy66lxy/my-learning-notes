# 模型插值

**模型插值（Model Interpolation）是把已有模型按一定比例组合，得到一个新模型。** 在个性化联邦学习中，常见做法是组合**全局模型与客户端自己的本地模型**。

全局模型包含各方共同学习的知识，本地模型更贴合自己的数据。插值就是调整两者各占多少：

\[ \text{个性化模型参数} =\alpha\times\text{本地模型参数} +(1-\alpha)\times\text{全局模型参数} \]

其中，\(\alpha\) 通常在 0～1 之间：

| \(\alpha\) | 含义               |
| ---------- | ------------------ |
| 0          | 完全使用全局模型   |
| 0.5        | 本地和全局各占一半 |
| 1          | 完全使用本地模型   |

**举一个具体例子：**

假设对应的某个参数，全局模型中是 **2**，甲的本地模型中是 **8**。甲选择本地占 75%、全局占 25%，组合后的参数就是：

\[ 0.75\times8+0.25\times2=6.5 \]

其他对应参数也按规则组合，就得到甲的个性化模型。乙可以选择不同的比例，因此得到不同的模型。

**比例如何确定？** 可以预先设置、用本地验证数据比较，或者由算法学习。更偏向本地不一定效果更好，需要验证。

它与普通聚合的区别是：

- **普通聚合**：把各客户端的更新汇成一个共同模型。
- **个性化模型插值**：为各客户端形成适合自己的模型组合。

这里讲的是**参数层面的插值**，通常要求模型结构及参数对应关系兼容；也有方法通过组合模型的预测结果实现插值。
