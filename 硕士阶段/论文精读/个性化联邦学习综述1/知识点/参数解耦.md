# 参数解耦

**参数解耦（Parameter Decoupling）是把模型参数分成不同部分，分别规定哪些参与共享、哪些留在本地个性化训练。** 它属于前面“策略 II”中的基于架构的方法。

例如，一个手写数字识别模型可以这样划分：

**输入图片 → 特征提取器 → 分类器 → 识别结果**

| 模型部分   | 作用                     | 一种划分方式                             |
| ---------- | ------------------------ | ---------------------------------------- |
| 特征提取器 | 提取笔画、形状等通用特征 | **共享参数**：各客户端训练后，上传并聚合 |
| 分类器     | 根据特征判断属于哪个数字 | **个性化参数**：各自在本地训练、保留     |

这样，甲、乙共同学习如何提取特征，同时各自调整分类器，以适应本地数据特点。

**每轮训练怎么进行？**

1. 甲、乙分别用自己的数据，训练共享部分和个性化部分。
2. **只上传共享部分的更新**，个性化部分留在本地。
3. 服务器聚合共享更新，并发回客户端。
4. 各客户端更新共享部分，保留自己的个性化部分，再继续训练。

因此，“共享参数”也会在客户端训练，只是训练后需要参与共同聚合。

**解耦的关键是分开管理与共享，并不表示两部分互不影响。** 它们仍然共同完成预测，训练时也会相互影响。
