# 问题根源：C++ string 不能直接用 `s[m] = xxx` 下标越界赋值

## 背景

```
#include <bits/stdc++.h>
#define int long long
#define endl "\n"

using namespace std;

const int N = 2e5 + 10;

void solve() {
	string str, substr;
	while(cin >> str >> substr) {
	    // 找ASCII值最大的那个字符
	    int n = str.size();
	    int ma = 0; // 下标
	    for(int i = 0; i < n; i++) {
	        if(str[ma] < str[i]) {
	            ma = i;
	        }
	    }
	    string s = "";
	    int m = 0;
	    // abc ab eee 
	    // 拼接第一部分
	    for(int i = 0; i <= ma; i++) {
	        s[m] = str[i];
	        m++;
	    }
	    // 第三部分
	    for(int i = 0; i < 3; i++) {
	        s[m] = substr[i];
	        m++;
	    }
	    // 第二部分
	    for(int i = ma + 1; i < n; i++) {
	        s[m] = str[i];
	        m++;
	    }
	    cout << s.size() << endl;
        
        // 初始化	    
	    str = "", substr = "";
	}
}

signed main()
{
	ios::sync_with_stdio(false), cin.tie(0);
	cout.tie(0);
	
	int t = 1;
	// cin >> t;
	while(t--) {
		solve();
	}
}
```

```
cout << s.size() << endl; // 为0
cout << s << endl; // 为空串
for(int i = 0; i < m; i++) {
	cout << s[i];
}
cout << endl; // 可以正常输出
```

## 核心原因

`string s = "";` 初始化后**字符串长度是 0**，它没有预先分配字符空间。

- `s[0]`、`s[1]`…… 这些下标位置**不存在内存**，属于**越界访问**。
- 直接 `s[m] = str[i]` 是非法操作，不会自动扩容字符串，字符串 `s` 的 `size()` 永远还是 0。
- 但你后面用 `for(int i=0;i<m;i++) cout<<s[i]` 刚好强行读取了这块越界内存，碰巧能打出内容，属于**未定义行为**，极不稳定，随时会乱码 / 崩溃。

## 两种正确改法

### 方法 1：使用 `push_back()` 尾部追加（最推荐）

不用手动维护 `m` 变量，直接往字符串末尾加字符：

```
// 删掉 int m=0;
string s;
// 第一部分
for(int i = 0; i <= ma; i++) {
    s.push_back(str[i]);
}
// 插入子串substr整段
s += substr;
// 第二部分
for(int i = ma + 1; i < n; i++) {
    s.push_back(str[i]);
}

cout << s.size() << endl;
cout << s << endl;
```

### 方法 2：先预分配 string 容量，再下标赋值

如果一定要用 `s[m] =`，必须先 resize 开辟空间：

```
int total = (ma+1) + substr.size() + (n - ma - 1);
s.resize(total); // 预先开好足够长度
int m = 0;

for(int i = 0; i <= ma; i++) {
    s[m++] = str[i];
}
for(char c : substr) {
    s[m++] = c;
}
for(int i = ma + 1; i < n; i++) {
    s[m++] = str[i];
}
```

# 问题根源：字典序 vs 数值大小

## 背景

```
#include <bits/stdc++.h>
#define int long long
#define endl "\n"

using namespace std;

const int N = 2000 + 10;

bool cmp(string a, string b) {
    return a < b;
}

void solve() {
	string s;
    cin >> s;
    string res = "";
    string a[N];
    int j = 0;
    for(int i = 0; i < s.size(); i++) {
        int x = s[i] - '0';
        a[j].push_back(s[i]);
        if(x % 2 == 0) j++;
    }
    sort(a, a + j, cmp);
    for(int i = 0; i < j; i++) cout << a[i] << endl;
}

signed main()
{
	ios::sync_with_stdio(false), cin.tie(0);
	cout.tie(0);
	
	int t = 1;
	// cin >> t;
	while(t--) {
		solve();
	}
}
```

## 核心原因

现在你的代码是**字符串字典序排序**：

`"10"` 和 `"2"` 做字符串比较：

第一位字符 `'1'` < `'2'`，所以字典序 `"10" < "2"`。

所以排序结果：`10，2，4`，这就是你现在实际输出。

但是你**想要按数字大小排序**：`2，4，10`。

> 字典序：`"10"<"2"`
>
> 数值大小：`10 > 2`

## 原来的 cmp

```
bool cmp(string a, string b) {
    return a < b; // 字符串字典序
}
```

这是按字符比较，不是按数字大小比较。

## 正确修改方法

**修改比较函数，按数字大小排序**

把 cmp 改成把字符串转成数字再比大小：

```
bool cmp(string a, string b) {
    long long numA = stoll(a);
    long long numB = stoll(b);
    return numA < numB;
}
```
