# 正则化

我们从一个问题重新理解：**模型要把本地数据学好，但如果只顾本地数据，会不会学得太偏？**

正则化就是在原来的训练目标之外，加入一种偏好或约束，影响模型最后选择什么样的参数。

### 1．先看没有正则化时，模型在做什么

假设客户端甲的模型参数是 \(\theta\)，本地损失为：

\[ f_{\text{甲}}(\theta)=(\theta-1)^2 \]

这意味着，甲只看自己的数据时，最喜欢：

\[ \theta=1 \]

因为这时本地损失是 0。

如果训练目标只有：

\[ \min_\theta f_{\text{甲}}(\theta) \]

模型就只需要考虑“怎样把甲的数据拟合好”。

但甲的数据可能很少、有噪声，或者只覆盖某些类别。**只把这批数据拟合好，不一定能识别未来的新样本，也不一定有利于共同训练。**

### 2．加入正则化：除了拟合好，还要考虑另一个要求

假设共同训练得到的全局参数是：

\[ w=3 \]

我们认为它包含值得保留的共同知识，因此希望甲在学习自己数据时，**不要轻易偏离这个参考位置太远**。

可以把目标改成：

\[ \min_\theta \underbrace{(\theta-1)^2}_{\text{拟合甲的数据}} + \lambda \underbrace{(\theta-3)^2}_{\text{偏离全局参考的惩罚}} \]

其中：

- 第一项：越贴合本地数据，越小。
- 第二项：越接近全局参考，越小。
- \(\lambda\)：控制第二项有多重要，叫**正则化系数**。

训练现在要同时权衡两个要求。

**注意：“惩罚”只是目标函数中的额外数值代价，不是禁止参数变化。**

### 3．模型怎样在两者之间折中？

先令 \(\lambda=1\)，比较几个候选参数：

| 本地参数 \(\theta\) | 本地损失 \((\theta-1)^2\) | 正则项 \((\theta-3)^2\) | 总目标 |
| ------------------- | ------------------------- | ----------------------- | ------ |
| 1                   | 0                         | 4                       | 4      |
| 2                   | 1                         | 1                       | 2      |
| 3                   | 4                         | 0                       | 4      |

这里，最优参数是 **2**。

它没有完全服从本地数据，也没有完全照搬全局模型，而是在两个要求之间折中。

> **正则化改变的是模型选择参数的标准：本地损失更小，不再是唯一标准。**

### 4．正则化系数和学习率有什么区别？

这两个很容易混淆：

| 设置                   | 控制什么                 |
| ---------------------- | ------------------------ |
| 学习率 \(\eta\)        | 每一步参数调整的幅度     |
| 正则化系数 \(\lambda\) | 训练目标中，约束有多重要 |

在刚才的例子里：

- \(\lambda=0\)：只考虑本地损失，最优参数是 1。
- \(\lambda=1\)：两项折中，最优参数是 2。
- \(\lambda\) 越大：最优参数越靠近全局参考 3。

**学习率主要影响“怎么走”；正则化系数会改变“想走到哪里”。**

而且，\(\lambda\) 的数值大小需要结合两项的尺度判断。不能跨不同公式，简单认为“系数都是 1，所以约束一样强”。

### 5．正则化怎样影响梯度？

训练时，模型不是先单独优化本地损失，再单独处理惩罚，而是对**总目标**求梯度：

\[ \nabla_\theta\left[f_{\text{甲}}(\theta)+\lambda R(\theta,w)\right] = \nabla_\theta f_{\text{甲}}(\theta) + \lambda\nabla_\theta R(\theta,w) \]

你可以把它理解为：

- 本地损失提供一个调整倾向。
- 正则项提供另一个调整倾向。
- 两者合起来，决定这一步怎样更新。

在刚才的例子中，一个倾向让参数靠近 1，另一个让参数靠近 3，最后在 2 处达到平衡。

这里的“两个倾向”是帮助理解的比喻，实际计算的是梯度相加。

### 6．正则化一定是“靠近全局模型”吗？

**不是。那只是联邦学习中的一种设计。**

正则化可以表达不同偏好：

| 正则化方式             | 希望模型具有什么特点             |
| ---------------------- | -------------------------------- |
| 惩罚参数过大           | 避免某些参数变得过大             |
| 惩罚偏离参考模型       | 保留共同知识或已有知识           |
| 对重要参数施加更强惩罚 | 尽量少改变被认为重要的参数       |
| 约束特征表示           | 让某些表示保持一致或满足指定关系 |

所以，阅读一个方法时，不能只看到“用了正则化”，就认为它一定在把本地模型拉向全局模型。**要看正则项具体约束了什么。**

### 7．在这篇联邦学习综述中，它有什么作用和代价？

在客户端数据不同的情况下，本地模型可能沿各自方向更新。适当的正则化可以限制某些偏离，帮助保留共同知识、缓解训练中的分歧。

但约束过强也有代价：

> 如果甲确实有不同于其他人的合理特点，强迫甲一直靠近共同模型，就可能妨碍个性化。

因此，正则化不是越强越好，也不保证一定提高测试准确率。

**你可以先这样记：正则化是在“把数据学好”之外，再告诉模型“我希望你以什么方式学、保留什么特点”，然后让两者共同决定结果。**
