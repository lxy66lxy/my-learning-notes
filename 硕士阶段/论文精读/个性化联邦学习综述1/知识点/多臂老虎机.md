# 多臂老虎机

名字借用了**老虎机的拉杆**这个形象。

传统老虎机侧面有一根拉杆，看起来像一只手臂，英语俗称 **“独臂强盗”（one-armed bandit）**：“独臂”指拉杆，“强盗”是戏称它容易让人输钱。

把它扩展成有多个拉杆的机器，每根拉杆的中奖概率和回报都不同，而且事先不知道，就形成了“多臂老虎机”的比喻。

所以，**每只“臂”代表一个可选项，拉动它代表尝试一次，得到的钱代表奖励。** 在客户端选择中，每个客户端就可以对应一只“臂”。

**多臂老虎机（Multi-Armed Bandit，MAB）是一类决策问题：面对多个收益未知的选项，怎样一边尝试、一边选择，让累计收益尽可能高。**

名字来自一个比喻：面前有多台老虎机，每台拉杆对应一个选择，但你不知道哪台的平均回报更高。“臂”就是一个可选项。

它的核心是平衡两件事：

- **探索（Exploration）**：尝试不熟悉的选项，了解它的收益。
- **利用（Exploitation）**：选择目前看来收益较好的选项。

例如，过去尝试发现，甲的平均奖励是 **8**，乙是 **5**，丙还没试过。

这时：

- 选甲，是利用已有经验；
- 试丙，是探索未知机会——丙可能更好，也可能更差。

如果一直探索，会浪费已有的好机会；如果一直选甲，又可能错过更好的丙。

**放到客户端选择中：**

| 多臂老虎机中的概念 | 对应联邦学习                     |
| ------------------ | -------------------------------- |
| 一只“臂”           | 一个可选客户端                   |
| 拉一次拉杆         | 选择该客户端参与训练             |
| 获得奖励           | 根据训练效果、耗时等评价这次选择 |

系统可以逐渐学习哪些客户端值得选择，同时保留一定探索机会。

与你刚才学的 DQN 相比，**两者都可以追求累计收益**。区别在于：经典多臂老虎机通常不显式考虑“这次选择怎样改变下一轮环境”；DQN 则会学习状态、行动与后续收益之间的关系。
