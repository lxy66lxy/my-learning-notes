# 算法计算器项目总结

这是本科期间使用 Android Studio 开发的安卓计算器项目，包含普通计算器与算法计算器两个入口。根据原博客，普通模式通过栈组织表达式计算，支持整数、小数与复合运算；算法模式将部分数学算法做成可交互的计算功能。

> 本总结依据原博客整理，尚未编译或运行项目。项目的实际可用范围仍需结合源码和测试确认。

## 页面与代码组织

| 文件               | 原文描述的作用                   |
| ------------------ | -------------------------------- |
| MainActivity.java  | 首页，进入普通计算器或算法计算器 |
| MainActivity2.java | 普通计算器的交互与计算逻辑       |
| MainActivity3.java | 算法计算器的交互与计算逻辑       |
| MathUtils.java     | 数学函数实现                     |
| activity_main.xml  | 首页布局                         |
| activity_main2.xml | 普通计算器布局                   |
| activity_main3.xml | 算法计算器布局                   |

## 原文介绍的算法功能

| 按钮名称   | 功能或原文说明                                               |
| ---------- | ------------------------------------------------------------ |
| POW        | 求幂，原文说明采用快速幂；该节示例代码疑似贴错，需复核       |
| POW_MODIFY | 带模数的幂运算，并介绍乘法逆元；适用条件需复核               |
| IS_PRIME   | 判断质数                                                     |
| GET_PRIME  | 筛选质数，原文介绍线性筛                                     |
| GCD        | 最大公约数（Greatest Common Divisor，GCD），用于找到两个整数共同的最大约数 |
| LCM        | 最小公倍数（Least Common Multiple，LCM），用于找到两个整数共同的最小正倍数 |
| GAUSS      | 高斯消元；原文明确说明应用中的该功能尚未完成                 |
| PHI        | 欧拉函数                                                     |
| EXGCD      | 扩展欧几里得算法（Extended Euclidean Algorithm），求解相应的整数系数关系 |
| LINEAR     | 线性同余方程                                                 |

## 可以在项目介绍中强调的实践

- 把算法练习中的数学函数接入安卓界面。
- 通过多个页面组织功能，使用按钮完成页面跳转与操作选择。
- 将数学函数放入独立类中，分开组织界面逻辑和计算逻辑。
- 给不同函数补充输入方式和使用说明，方便理解与演示。
