# 元学习

**“学习如何学习”**：通过经历多个任务，让模型在遇到新任务时，能够用较少的数据和训练步骤完成适配。

例如，甲的手写数字偏倾斜，乙的比较圆。我们希望新来的丙，用少量自己的手写样本，就能得到适合自己笔迹的模型。

**① 下载已经过元学习训练的初始模型**

这个模型已经从甲、乙等人的任务中学到了一个便于适配的起点。丙从这里继续训练。

**② 准备自己的手写数字，并标注答案**

例如，丙写了一张“2”的图片，就给它标上正确答案“2”。这些是让模型认识丙笔迹的训练样本。

**③ 在本地微调模型**

把自己的样本输入模型。如果把“2”认成了“7”，就根据预测错误调整参数。经过若干次更新，得到丙的个性化模型。

**④ 用没参加训练的笔迹样本检查效果**

再写一些新样本测试，看看模型是否真的适应了丙的笔迹。

整个过程是：

**元学习得到的起点 → 丙的标注样本 → 本地微调 → 丙的个性化模型**

这里的本地微调通常可以由丙独立完成。**元学习的价值，是努力让丙用更少的样本和更新步骤完成适配**；具体需要多少，还要看任务和实际测试结果。

**元学习做的关键事情，是提前训练出一个“容易被丙微调好”的初始模型。** 这发生在丙下载模型之前。

它利用甲、乙等客户端，反复进行这样的练习：

1. 从共同起点出发，让甲、乙分别训练几步。
2. 检查各自**微调后的效果**。
3. 根据这些效果，调整共同起点，让下次适配更容易。

因此，放回刚才的流程：

**元学习：训练容易适配的起点 → 丙下载这个起点 → 丙用自己的数据微调。**
