# 技巧之字符串

### 读入带空格的字符串，且==读入会把本行的回车一起吸收掉==--getline()

```
string str;
getline(cin, str);
cout << str << endl;
```

```
string a, b;
getline(cin, a);
getline(cin, b);
cout << a << endl;
cout << b << endl;
```

### 将字符串==按照空格分开==--stringstream

```
string str;
getline(cin, str);
stringstream line(str);
string s;
while(line >> s) {
	cout << s << endl;
}
```

### getline()读取数据的时候会读取到上一次换行的换行符，此时需要有函数来吸收--cin.ignore()

```
int x;
cin >> x; // 后面带有一个回车
string str;
cin.ignore();
getline(cin, str);
cout << str << endl;
```

**等价**

```
int x;
cin >> x;
string str;
getline(cin, str); // 吸收掉回车
getline(cin, str); // 正常读入
cout << str << endl;
```

# 技巧之__int128快读快写

### __int128快读

```
inline __int128 read(){
    __int128 x = 0, f = 1;
    char ch = getchar();
    while(ch < '0' || ch > '9'){
        if(ch == '-')
            f = -1;
        ch = getchar();
    }
    while(ch >= '0' && ch <= '9'){
        x = x * 10 + ch - '0';
        ch = getchar();
    }
    return x * f;
}
```

### __int128快写

```
inline void print(__int128 x){
    if(x < 0){
        putchar('-');
        x = -x;
    }
    if(x > 9)
        print(x / 10);
    putchar(x % 10 + '0');
}
```
