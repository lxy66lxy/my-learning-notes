# 归一化和标准化

## 归一化

* 将数据缩放到[0,1]的范围

* 计算方法：x=(x-min)/(max-min)

**1. 归一化：把数据缩放到指定范围，通常是 0～1。**

常用公式是：

\[ 新值=\frac{原值-最小值}{最大值-最小值} \]

例如，数据是 **10、20、30**，归一化后分别是：

| 原值 | 归一化后 |
| ---- | -------- |
| 10   | 0        |
| 20   | 0.5      |
| 30   | 1        |

它表达的是：**这个数在最小值和最大值之间，处于什么位置？**

## 标准化

* 将数据转换到0值附近
* 转换函数：x=(x-均值)/标准差

**2. 标准化：把数据转换成“距离平均值有多远”。**

常用公式是：

\[ 新值=\frac{原值-平均值}{标准差} \]

**标准差**表示数据的分散程度：越大，数据之间的差别通常越大。

假设全班成绩平均 **70 分**，标准差是 **10 分**：

- 80 分 → \((80-70)/10=1\)，比平均值高一个标准差。
- 70 分 → 0，正好等于平均值。
- 60 分 → −1，比平均值低一个标准差。

处理后的数据平均值为 **0**，标准差为 **1**，数值范围没有固定限制。它也**不会自动把数据变成正态分布**。

## 好处是什么？

**主要好处是：让不同数据的尺度更协调，帮助模型更稳定地学习。**

1. **减少“大数字占优势”的影响**
   比如年龄是 20～60，收入是 3,000～30,000。在计算样本之间的距离时，收入的数字变化可能盖过年龄。缩放后，两者能在更接近的尺度上参与计算。
2. **让训练更稳定，常常也更快**
   不同特征的尺度差别太大时，模型调整参数可能不协调。处理后，通常更容易选择合适的调整步幅，让训练顺利进行。
3. **让数值更容易比较和理解**  
   - **归一化**：便于看一个数在整体范围中的位置，例如 0.8 表示比较靠近最大值。
   - **标准化**：便于看一个数偏离平均水平多少，例如 2 表示高出平均值两个标准差。

它们对**依赖距离计算或需要反复调整参数的模型**尤其有帮助。实际是否提高准确率，还需要通过实验判断。
